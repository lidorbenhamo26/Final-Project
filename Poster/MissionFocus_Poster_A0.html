01

Background & Need

Executive-function assessment still leans on questionnaires (BRIEF-A) and dry lab drills:

  • Stressful & repetitive — scores drop with motivation, not ability
  • Low engagement, especially for children and young adults
  • Subjective ratings — little objective, trial-level performance data
The need: measurement that is objective, repeatable — and actually fun to take.
02

The Solution

Mission Focus turns assessment into a 10-minute space mission:

  • A first-person astronaut keeps a failing station alive
  • Every repair console is a cognitive paradigm in disguise
  • Every reaction is silently logged — no test anxiety, no clipboards
  • One click: assessor-ready HTML report + analysis-ready CSV
03

Main Requirements

  • Playable 10-min mission — tutorial + voice guidance, not a quiz
  • Measure attention, working memory, inhibition, planning and response accuracy
  • Per-trial logging: reaction time, accuracy, omissions, false alarms
  • Assessor tools: freeze (F11) and live report overlay (F12)
  • Export HTML report + per-task CSV summary per participant
  • Local-only data — privacy by design, no network

Testing & Evaluation

  • Quick-test mode — the full pipeline exercised in 30-second missions
  • Deterministic seeds — reproducible trial sequences for debugging
  • Assessor console verified mid-mission — F11 freeze, F12 live report
  • Locale-safe CSV — opens clean in Excel, R and Python
  • Pilot playtests + peer-examiner demo ahead of the exhibition
08

Challenges & Insights

  1. Fun vs. validity — free-roam play, yet strict stimulus timing and response windows inside every console
  2. Invisible measurement — world-space consoles and voice guidance keep the "test" out of sight
  3. Many paradigms, one core — a shared task framework: a new cognitive task is one script, metrics flow to reports automatically
  4. AI asset pipeline — AI-generated 3D models needed URP material and scale rework
Players forget they are being measured — and strict timing is exactly what keeps the data meaningful.
